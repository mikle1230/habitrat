# 设置页设计

## PIN 存在即锁定

- 设置页含不需要让孩子日常看到的内容，方案为 **「PIN 存在即锁定」**：
  - **未设置 PIN** → 设置页完全开放（新朋友拿到能正常配置，分享体验不受影响）；
  - **已设置 PIN** → 进入设置页显示锁屏「🔒 设置已被锁定」，需输入 PIN；
  - 解锁后本次停留可操作，**切到别的 tab 再回来重新上锁**。
- 实现挂在 `switchView`，离开设置页时重置解锁状态。

## 自动保存（无手动保存按钮）

- **移除「保存设置」按钮**——所有设置项（孩子名称、家庭成员、习惯管理、PIN、寒暑假日期）编辑后**自动保存**，轻提示「✅ 已自动保存」。
- 原「保存设置」按钮只保存寒暑假配置，名不副实，是移除的直接原因。

## 模块分组排序

最终顺序（**同步与安全最上**，家长 PIN 最优先）：

1. **🔐 同步与安全**：家长 PIN、跨设备同步
2. **👧 基础信息**：孩子名称、家庭成员
3. **📋 习惯**：习惯管理（高频优先）
4. **🏖 假期**：寒暑假日期
5. **💾 数据管理**：备份/恢复、重置（危险操作下沉）

## 游戏规则（数据驱动）

- Ratty 页场景下方放「📜 游戏规则」卡片 → 点击弹窗（孩子常去 Ratty 页）。
- 规则内容**存放在独立数组数据中**，将来改内容只改数组、不用翻代码逻辑，方便家长随时变更。
- 文案细节：把「不会偷偷改掉」改为「避免不小心误操作」；「寒暑假的规则」改为「寒暑假的时间段」。
