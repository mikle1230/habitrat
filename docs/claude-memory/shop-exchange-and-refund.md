# 商店兑换与退回

## 兑换记录

- 兑换数据本身写入 `transactions`（`spend_coin` 类型），但**旧版页面不展示**；新版商店页新增「📜 兑换记录」区块。
- 每条记录三要素：**时间**（精确到分钟，`2026-08-02 14:30`）+ **用途**（项目 × 数量）+ **金币**（`-20` 红色）。
- **倒序排列**（最新在上），超出 260px 自动滚动；无记录时显示「还没有兑换记录」。
- **手机端两行卡片式布局**：第一行时间（左）+ 金额（右，红色加粗），第二行用途（左，`word-break: break-all` 完整换行）+ 操作按钮（右）——单行放不下时不再截断。

## 兑换前确认（防误操作）

- 点击「兑换」弹出确认框：**「兑换『看电视』x2，扣除 20 金币？」**——商店页和积分面板两处入口都加了。

## 家长退回（防白嫖）

- **退回仅限家长**（最终纠错权），权限/时机是核心设计点，防止「白嫖循环」（兑换→享受→退回=免费享受）。方案：**兑换前确认 + 家长 PIN 退回（无限制，家长自行判断）**。
- 退回流程三步：① **PIN 验证**（家长 PIN；未设置 PIN 时直接弹确认）② **填写退回理由**（必填弹窗，如「误操作」「奖励未享受」）③ 确认退回。
- 退回后：金币**加回余额**，原兑换记录变灰 + 标签「↩️ 已退回」+ 追加「（已退：理由）」；新增绿色 `+X` 退回记录，显示「退回：原项目（理由）」；操作日志同步记录。
- 「📜 兑换记录」**同时显示兑换和退回**，按时间混合排序。
- 金币统计：**退款计入收入，已退款兑换不计入支出**。
